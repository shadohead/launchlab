# Old TCRT5000 / LM393 sensor

[Parts list, quantities and purchase links](PARTS.md) are in the parts guide.

The **Sidecar form factor** mounts the M5 on its own carrier beside this sensor attachment. Sidecar describes the mounting layout; select firmware for the sensor you actually use.

This is the older, larger blue analog sensor module, separate from the small QRE1113 build. Use its **analog AO** output. DO remains disconnected. The current **0.13.9** firmware supports it directly: install it with the [web updater](https://launchlab.beywatch.gg/update), then choose **Menu → Settings → Sensor profile → TCRT5000**. There is no sensor auto-detection. The frozen **0.2.0-sticks3-tcrt5000** firmware remains available below.

| TCRT5000 module | M5StickS3 K150 Hat |
| --- | --- |
| AO | G1 / GPIO1 |
| VCC | 3V3 / 3V3_L2 |
| GND | GND |

Verify your module's physical pin labels. Do not power it from the 5 V Grove red lead or use GPIO0 as the analog input. The TCRT5000 profile (unchanged since 0.10.18, retained in 0.13.9) uses a 60-count minimum mark, for this module's weaker marks, with 70% reversal hysteresis at 50 kS/s; a TCRT5000 setup detected six of six physical pulls on it. The old 0.2.0 build uses an 80-count minimum.

## Bundled LaunchLab TCRT5000 Sidecar hardware

Use the **TCRT5000 sensor v102** and **Sidecar v2** cover/base pair.
The sensor has uniform-height hinge blocks and captive print-in-place launcher clips.
There is no top sensor retainer and no clip screw.
Use the existing M3 board screw (M3×6 CAD reference), checking board/header dimensions, actual preload and optical alignment.
Sidecar mounts the M5 independently using two M2×4 screws into its secondary back holes.
Thread the leads through the enclosed left-side exit before snapping on the M5 snap cover.

For PETG, open the saved TCRT PLA 3MF as a project, select your printer and PETG filament profile, retain both HINGE SUPPORT BLOCKER objects and the captive-clamp pose, and reslice. Importing only the STL loses those blockers. Do not print the saved PLA G-code with PETG.

- [TCRT v102 STL/source package](../site/public/hardware/downloads/standard-sensor-v102.zip) and [P1S PLA sensor plate](../site/public/hardware/downloads/standard-sensor-v102.3mf).
- [Sidecar v2 STL/source package](../site/public/hardware/downloads/sidecar-v2.zip), [P1S PLA pair](../site/public/hardware/downloads/sidecar-v2-pla.3mf) and [P1S PETG pair](../site/public/hardware/downloads/sidecar-v2-petg.3mf).

These are separate sensor and mount-pair source plates, not a combined full-kit plate.
Retain both sensor hinge support blockers and re-slice for your printer and filament.
CAD, STL readback and saved print-project audits passed; physical fit, retention, fatigue, solder clearance and optical alignment remain unverified.
Choose **Settings → Mounting → Top or Sidecar** to match the physical layout; display flip is a separate setting.

## Restore the saved old-sensor application

Download the [old TCRT firmware release](https://github.com/shadohead/launchlab/releases/tag/firmware-tcrt5000-v0.2.0). This is an application-only image for an M5StickS3 K150 that already has the LaunchLab `default_8MB` partition layout. It is not a factory-board first-install bundle. The browser updater installs the current 0.13.9 firmware, not this old build.

With Espressif esptool installed, enter download mode and replace `YOUR_SERIAL_PORT` with the device's port:

```sh
python3 -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 \
  write-flash 0x10000 firmware/releases/0.2.0-sticks3-tcrt5000/LaunchLabMini.ino.bin
```

Preserve the bootloader/partitions and verify the device write checksum. The saved image is 619,408 bytes and its SHA-256 is `8f60898d0a4fd3e9e6cf16c741ada3ac50949d21f52ab84574b8c54e09a5dec6`. The runtime version still reads `0.2.0-sticks3-acquisition`; it was not rebuilt or retuned for publication.

The original trial had three user-confirmed pulls, three device detections and three saved-waveform replay results. It is not independent absolute RPM calibration and does not validate the newer printed mounts. This earlier acquisition build does not supply the QRE 0.7.0 history/trend/Motion/Recreate UI described in the [current firmware guide](../firmware/LaunchLabMini/README.md). Historical READMEs retain development-era commands and private evidence references; those backups and practice captures are not part of the public package. Use this guide for public restore paths.
